### Paleta elegida — Café + Azul Marino

| Token | Hex | Descripción |
|---|---|---|
| `--text-h` | `#1B3A6B` | Azul marino — Headings |
| `--text` | `#5C4233` | Café medio — Cuerpo |
| `--accent` | `#2B5EA7` | Azul vibrante — Links/botones |
| `--accent-2` | `#A0714F` | Café dorado — Secundario |
| `--bg-light` | `#F4F1EC` | Crema — Fondo Light mode |
| `--bg-dark` | `#111318` | Profundo — Fondo Dark mode |

>Solo el fondo cambia entre modos. Los demás colores son fijos.
